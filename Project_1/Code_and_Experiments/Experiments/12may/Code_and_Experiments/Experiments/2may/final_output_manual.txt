รายงานประจำปี พ.ศ. ๒๕๖๙

ชื่อโครงการ: การพัฒนาระบบสารสนเทศ

วันที่เริ่มต้น: ๑ มกราคม พ.ศ. ๒๕๖๙
วันที่สิ้นสุด: ๓๑ ธันวาคม พ.ศ. ๒๕๖๙

รายละเอียด:

โครงการนี้มีวัตถุประสงค์เพื่อพัฒนาระบบให้มีประสิทธิภาพมากขึ้น โดยมีงบประมาณทั้งหมดจำนวน
๕๐๐,๐๐๐ บาท และมีบุคลากรที่เกี่ยวข้องจำนวน ๓๐ คน

ผลการดำเนินงาน:

๑) วิเคราะห์ความต้องการของผู้ใช้งาน จำนวน ๓๐ ราย
๒) ออกแบบระบบเสร็จสมบูรณ์ภายใน ๖๐ วัน

๓) ทดสอบระบบจำนวน ๒ รอบ
๔) ปรับปรุงและนำไปใช้งานจริง

สรุป:
